# Data Model: In-Memory Python Console TODO Application

## Task Entity

### Attributes
- **id**: Integer (auto-incrementing, unique, required)
  - Generated by Task Manager
  - Starts from 1 and increments for each new task
- **title**: String (required, non-empty)
  - Maximum length: 200 characters
  - Minimum length: 1 character
- **description**: String (optional)
  - Maximum length: 2000 characters
  - Can be empty or null
- **status**: String (required)
  - Enum values: "pending", "in_progress", "completed"
  - Default value: "pending"
  - Valid transitions: pending → in_progress → completed (no backwards transitions)
- **priority**: String (required)
  - Enum values: "low", "medium", "high"
  - Default value: "medium"
- **created_at**: DateTime (required)
  - Set automatically when task is created
  - Format: ISO 8601
- **updated_at**: DateTime (required)
  - Set automatically when task is created or updated
  - Format: ISO 8601
  - Updated on every modification

### Validation Rules
- Title must not be empty or only whitespace
- Status must be one of the allowed values
- Priority must be one of the allowed values
- ID must be unique across all tasks
- created_at and updated_at must be valid timestamps

### State Transitions
- A task can transition from "pending" to "in_progress"
- A task can transition from "in_progress" to "completed"
- A task can transition from "in_progress" back to "pending"
- A task cannot transition from "completed" to any other state
- A task cannot transition directly from "pending" to "completed" (must go through "in_progress")

## Task Manager

### Responsibilities
- Maintain the collection of all tasks
- Generate unique IDs for new tasks
- Provide CRUD operations for tasks
- Validate all task operations
- Update timestamps appropriately

### Data Structure
- Store tasks in a dictionary with ID as key and Task object as value
- Maintain an auto-increment counter for ID generation
- Provide methods for all required operations

### Constraints
- No global mutation outside the Task Manager
- All data access must go through Task Manager methods
- Thread safety not required (single-user application)
